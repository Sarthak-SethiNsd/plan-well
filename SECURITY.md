# Security Policy

## Supported Versions

We actively provide security updates for the following versions of Plan Well:

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| 1.0.x   | No        |

---

## Reporting a Vulnerability

We take the security of Plan Well seriously. If you believe you have found a security vulnerability in this application, please report it to the maintainers as follows:

1. **Do not open a public issue.** Security flaws should be handled via private channels first to protect users.
2. Email your findings privately to the repository maintainers or administrative contacts.
3. Include detailed instructions to reproduce the vulnerability (including proof of concept scripts or screenshots where applicable).

### Response Process

* You will receive an initial acknowledgment of your report within 48 hours.
* We will investigate and coordinate a patch or mitigation strategy.
* Once resolved, a security advisory and a patched release will be published.
* We appreciate your coordination in keeping the vulnerability details private until a public patch is ready.
