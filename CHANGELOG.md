# Changelog

## 1.0.0 - 2026-07-03

### Added

- Personalized 7-day Indian meal plan generation.
- State, diet preference, weight, and meals-per-day inputs.
- Google Sign-In and Sign-Out.
- Firestore user profile saving.
- Automatic saving of generated meal plans for signed-in users.
- My Meal Plans page with saved-plan viewing and deletion.
- Feedback submission for signed-in users.
- About page powered by editable JSON content.
- Responsive dark green interface with white cards and accessible contrast.

### Notes

- This is the first release-ready version of Plan Well.
